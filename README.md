# ci-cd-final-project
## Project Name
Continuous Integration and Continuous Delivery (CI/CD) Final Project

## Description
This project demonstrates the implementation of a CI/CD pipeline using GitHub Actions, Tekton, and OpenShift.

## Objectives
- Automate code linting using GitHub Actions.
- Run unit tests.
- Create Tekton tasks.
- Build an application image.
- Deploy the application using OpenShift Pipelines.
